## STK Image Analysis Template

Prior to running, upload zip folder (contains: ImageResults folder, correct Array Layout) with the upload file button.

### Versions:
- Version 0.2.2 and earlier versions: enrichment contains Array Layouts 86312, 86402, 86412, 87102
- Version 0.2.3: enrichment contains Array Layouts 86312, 86402, 86412, 87102, 87202
- Version 0.2.8: Bug of not saving replaced spot is resolved. Enrichment of UKAdb 0.5.0
- Version 0.2.10: New grid, grid checker and qt operators. The new versions of the Grid and QT operators are faster. The new Grid checker operator has a resolved bug caused by the new grid button.
